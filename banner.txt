#################################################################################################################################

 Z2Z is a migration tool for Zimbra environments with the following features:

 - Migration between Zimbra servers, regardless of version or edition (Open Source/Network/Carbonio)
 - Allows replacing the server hostname during the process
 - Exports Class of Service (COS), user accounts, aliases, plus distribution lists

 (FOR MORE INFORMATION, PLEASE REFER TO *README.md* AND *INSTALL*)

#################################################################################################################################

 GUIDELINES AND LIMITATIONS (RECOMMENDED READING) for this version:

 - Exports LDAP entries into the export directory
 - Generates a batch export file containing all accounts in the environment
    - (Allows you to define your preferred mailbox import strategy)
 - Generates the "importar_ldap.sh" script to automate the LDAP entry import process
    - (Requires manually creating target domains in the new environment beforehand)
 - Generates the "script_import_FULL.sh" script to import all exported mailbox archives
 * Compatible with Single-Server and Multi-Server environments****
 **** Only compatible with Multi-Server environments that do not require hostname changes for more than one Mailbox server
 * Does not export environment-level server configuration (must be configured manually on the new server)
